# 無料版：Googleスプレッドシートで動かす

Googleスプレッドシート＋Apps Script だけで動く版です。**費用0円・サーバー不要・クレジットカード不要**。
Google Cloud の設定や「このアプリは確認されていません」の警告もありません。

```
Square（シフト公開）
   │  10分ごとに自動で確認
   ▼
スプレッドシート（会社アカウント）── 店舗カレンダーに「【出勤】氏名」
                                 └─ スタッフ本人のカレンダーにも「【出勤】氏名」
```

## サーバー版との違い

| | 無料版（これ） | サーバー版 |
| --- | --- | --- |
| 費用 | 0円 | 月5ドル程度 |
| 反映までの時間 | 最大10分 | すぐ（Webhook） |
| 管理画面 | スプレッドシート（スマホアプリOK） | Webページ |
| スタッフ本人のカレンダー | 本人が会社アカウントにカレンダーを共有 | 本人がGoogleで連携 |
| Google Cloud の設定 | 不要 | 必要 |

## 準備するもの

- **会社のGoogleアカウント**（店舗カレンダーを持っているアカウント）
- **Squareのアクセストークン**（[Square Developer Dashboard](https://developer.squareup.com/apps) でアプリを作成 →「Credentials」→ **Production** の Access token）

## セットアップ

> 手順1〜2は「Apps Script」の画面を使うため、パソコン、またはスマホのChromeで「PC版サイト」に切り替えて行ってください。手順3以降はスプレッドシートアプリでもできます。

### 1. スプレッドシートを作ってスクリプトを貼る

1. **会社アカウント**で [Googleスプレッドシート](https://sheets.new) を新規作成（名前は「シフト連携」など）
2. メニューの「拡張機能」→「Apps Script」
3. 最初から入っている `function myFunction() {...}` を全部消し、[`Code.gs`](Code.gs) の中身を**すべて**コピーして貼り付け
4. 💾（保存）を押す

### 2. 初期設定を実行する

1. 上の関数の選択欄で **`setup`** を選び、「実行」
2. 「承認が必要です」→「権限を確認」→ 会社アカウントを選ぶ →「許可」
   - 自分で作ったスクリプトなので「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」で進めます
3. スプレッドシートに戻ると「設定」「店舗」「スタッフ」「同期ログ」シートができています

### 3. Squareのアクセストークンを入れる

「設定」シートの **Squareアクセストークン** の値の欄に、トークンを貼り付け。
→ 自動で隠され（「設定済み」と表示）、「店舗」「スタッフ」シートにSquareの店舗とスタッフが読み込まれます。

### 4. 店舗ごとのカレンダーを選ぶ

「店舗」シートの **書き込み先カレンダー** を、プルダウンから選ぶ（会社アカウントの「カレンダーを追加」で作ったカレンダーが出てきます）。

- 空欄 → 「設定」シートの **既定の店舗カレンダー**（空欄ならメインカレンダー）
- 「（書き込まない）」→ その店舗は店舗カレンダーに入れない

### 5. スタッフのカレンダーを会社アカウントに共有する

スタッフ本人のカレンダーに直接入れるには、**スタッフのGmailアカウント側**で、カレンダーを会社アカウントに共有します（会社がアカウントを管理している場合は、会社側でまとめて設定できます）。

1. スタッフのGmailアカウントで、パソコン（またはスマホのChromeのPC版サイト）から [Googleカレンダー](https://calendar.google.com/) を開く
2. 右上の ⚙ →「設定」→ 左の「マイカレンダーの設定」で自分の名前を選ぶ
3. 「特定のユーザーまたはグループと共有する」→「ユーザーやグループを追加」
4. **会社アカウントのメールアドレス**を入力し、権限を **「予定の変更」** にして「送信」

> 共有していないスタッフにも、店舗カレンダーの予定から**招待メール**が届くので、シフトは確認できます（あとで共有すると、自動で直接書き込みに切り替わります）。

「スタッフ」シートの **本人カレンダー（Gmail）** は、Squareに登録されたメールが最初から入っています。別のGmailを使う場合は書き換えてください。

### 6. 同期する

「設定」シートの **今すぐ同期** にチェックを入れる → 数十秒で同期され、**最終同期** に結果が出ます。
以降は**10分ごとに自動**で同期します。

「スタッフ」シートの **状態** 列で、スタッフごとの状況を確認できます。

| 状態 | 意味 |
| --- | --- |
| ✓ 本人カレンダーに直接書き込み | 完了 |
| △ カレンダー共有が未設定（招待メールで送信） | 手順5の共有をすると直接書き込みになります |
| △ 共有の権限が「予定の変更」ではありません | 手順5の権限を「予定の変更」に直してください |
| ✗ 送信先なし | 「本人カレンダー（Gmail）」を入力してください |

## 動作の仕組み

| Square側の操作 | 本人のカレンダー | 店舗カレンダー |
| --- | --- | --- |
| シフトを公開 | 予定を追加 | 予定を追加 |
| 時間・メモを変更して再公開 | 更新 | 更新 |
| 担当スタッフを変更 | 前の人から削除し、新しい人に追加 | 更新 |
| 店舗を変更 | 更新 | 前の店舗カレンダーから削除し、新しい方に追加 |
| シフトを削除 | 削除 | 削除 |
| 下書きのみ | 何もしない | 何もしない |

- 予定タイトルは「【出勤】氏名」。「設定」シートの **予定タイトル** で変更できます（`{name}`=氏名, `{location}`=店舗名, `{job}`=職種）
- 店舗名は予定の「場所」、職種・メモは「説明」に入ります
- 新しいスタッフ・店舗は同期のたびに自動でシートに追加されます

## 無料枠について

Googleの無料アカウントでも十分収まります（目安）。

| 項目 | Googleの上限（無料アカウント） | この仕組み |
| --- | --- | --- |
| 自動実行の合計時間 | 1日90分 | 10分ごと × 数秒〜十数秒 |
| 予定の作成 | 1日5,000件 | 新しいシフトの数 × 2 |
| 外部への通信 | 1日20,000回 | 1回の同期で数回 |

## 困ったとき

- **「同期ログ」シート**に毎回の結果とエラーが記録されます
- コードを新しくするときは、Apps Script の中身を新しい `Code.gs` に貼り替えて保存するだけです（設定やシートはそのまま）
- 自動実行を止めたいときは、Apps Script の左の ⏰（トリガー）から `syncShifts` を削除
